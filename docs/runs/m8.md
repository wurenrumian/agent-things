# 实验记录 — M8 会话 UX（fork / diff / cost）与 `agent-things` CLI

**日期**：2026-10-03
**模型**：`xiaomi/mimo-v2.6-flash`（来自仓库根 `.env` 的 `OPENROUTER_MODEL`）
**环境**：Node `v24.13.1`，pnpm `10.30.1`，`tsx` transpile-only。
**命令**：

```bash
# 服务端 E2E（默认 8787 被占用，改用 8789；AGENT_CWD=./data/sandbox）
$env:PORT='8789'; pnpm --filter @agent/server start

# CLI 验收
pnpm --filter @agent/cli start -- --help
pnpm --filter @agent/cli start "list the files here"

# 质量门
pnpm typecheck
pnpm --filter @agent/web build
```

## 0. 方法

这一里程碑没有新"机制"，而是把已有内核以三种方式暴露出来，所以证据分三类：

1. **HTTP E2E（真实模型）**：起真实服务端，用 3 个真实 API turn 让 agent 写一个文件，
   然后读 `GET /api/sessions/:id/events` 证明 **`mechanism` diff 事件**确实出现；
   再 `POST …/fork` 证明**前缀复制**与**新鲜事件日志**。
2. **CLI 真实 turn**：`pnpm --filter @agent/cli start "list the files here"` 走同一
   `@agent/core` 内核，打印事件、usage 与 cost。
3. **静态门**：`pnpm typecheck`（core/server/web/cli）与 `pnpm --filter @agent/web build`。

服务端 3 次调用的成本合计约 **$0.00030**；CLI 两个 turn 各约 **$0.0002**。

## 1. Fork（core `Store.forkSession` + `POST /api/sessions/:id/fork`）

源码会话 6 条消息（user → assistant → tool → assistant → tool → assistant）。

```text
SESSION 4d93a793-e37c-4b2f-ba75-f3f550c1a0c0
SRC_MSGS 6 FORK_MSGS 1
FORK id=8e44d57c-ce0b-49f2-9ee3-c53d5a99e9c3 title=m8-e2e (fork) messageCount=1
FORK_FIRST_EQUAL True
FORK_EVENTS_RAW []
FORK_FULL messageCount=6 title=m8-e2e (fork)
FORK_404_STATUS 404
```

- `POST …/fork {atMessageIndex:1}` → 新会话只有 **1** 条消息，且内容与源第 1 条**逐字相等**。
- 新会话标题默认 `${source.title} (fork)`；源会话 **未被改动**（仍 6 条）。
- `FORK_EVENTS_RAW []`：新会话的事件日志是**空的**（故意不复制"发生了什么"）。
- `POST …/fork {}`（不带 index）→ 复制全部 6 条。
- 未知 id → **404**。

Web 侧：`SessionPicker` 顶部 **⑂ Fork** 按钮（从最新消息 fork），以及每条 assistant
消息 hover 出现的 **⑂ fork here**（`atMessageIndex = index + 1`）；两者都走同一路由并
选中新分支。

## 2. Diff（core `unifiedDiff` + `compose.ts` 包装 + web Diff tab）

真实 turn：`Create a file named m8-e2e.txt … containing exactly this line: hello m8 diff`。

```text
SSE_BYTES 9785 HAS_TURN_END True
DIFF_COUNT 1
DIFF path=m8-e2e.txt added=1 removed=0
PATCH<<
@@ -1,0 +1,1 @@
+hello m8 diff
>>
USAGE prompt=902 completion=49 cached=896 cost=9.502E-05
USAGE prompt=953 completion=26 cached=896 cost=9.419E-05
USAGE prompt=992 completion=63 cached=896 cost=0.00010884
FILE m8-e2e.txt 14b
```

- `compose.ts` 在 `write_file`/`edit_file` 执行前后读目标（相对 `ctx.cwd`；缺失记 `""`），
  字节变化时把一条 `mechanism` 事件塞进 `ToolResult.events`：
  `{ name:"diff", phase:"file", data:{ path, added, removed, patch } }`。
- 该事件由循环在 `tool.result` **之后**中继（源事件序列里可见 `… tool.result, mechanism,
  context.compiled …`），**从不进入模型上下文**；文件未变或调用失败时**不产生**事件。
- `patch` 是纯函数 `unifiedDiff()` 产出的 **hunks-only** 统一 diff（无依赖）。文件
  `hello m8 diff\n`（14 字节）计为 **+1 / −0**，尾随换行不再产生幻影空行。
- Web：新增 **Diff** tab，仅当至少存在一条 diff 时才出现；`+` 绿、`-` 红、上下文灰，
  每张卡片头部显示路径与 `+n / −n`。

纯函数自检（零 API）：

```text
trailing-newline add: "@@ -1,0 +1,1 @@\n+hello m8 diff"
modify:               "@@ -1,3 +1,3 @@\n a\n-b\n+B\n c"
identical:            ""
```

## 3. Cost 面板（web `UsageTab`）

在两张卡片之上新增一个 **session 标题栏**，一屏给出简报要求的全部信息：

- 主数字：**总花费**（`$0.0002` 级别，等宽大字号）；
- 指标格：**prompt / completion / cached token 总数 + 命中率**；
- 下方沿用 `bar-cache` 进度条表示命中率。

原先的 "Session running" 汇总卡被这个标题栏取代（避免重复），"This turn" 卡与逐次调用
表格、`Σ` 行保持不变，running 命中率/累计花费仍在表格里。

## 4. CLI — `packages/cli`（`@agent/cli`，bin `agent-things`）

`--help`：

```text
agent-things — drive the @agent/core kernel from the terminal.

Usage:
  agent-things [options] [message...]

Options:
  --cwd <dir>               Working directory for tools (default: cwd)
  --model <id>              OpenRouter model id (default: OPENROUTER_MODEL)
  --permission-mode <mode>  yolo | standard | readonly (default: yolo)
  --message, -m <text>      Run one turn, then exit
  --help, -h                Show this help

With no message, starts a REPL. Configuration is read from the repo-root
.env (OPENROUTER_API_KEY, OPENROUTER_MODEL, ...); real env vars win.
This is the same kernel the server and web app use.
```

验收 turn `pnpm --filter @agent/cli start "list the files here"`：


`--message` 单轮（验证文本渲染）：

```text
> Reply with exactly: HELLO FROM CLI
HELLO FROM CLI
[usage] prompt 716 · completion 14 · cached 640 · $0.0001
[turn.end] stop
[total] 1 call(s) · prompt 716 · completion 14 · cached 640 · cost $0.0001
```

没有消息时进入 `node:readline` REPL（`agent-things> ` 提示符，`exit`/`quit` 退出）。
CLI 只依赖 `@agent/core`（workspace link）+ `tsx`（devDep），自己带一个极小的 `.env`
加载器与参数解析器，**不 import server**。

> **观察（既有行为，非 M8 变更）**：内核 `Agent.run` 里 `onText`/`onRequest` 回调调用
> 的 `emit()` 返回值没有进 generator，所以 `text.delta`（及 `request.sent`）**当前不会
> 被发出**；文本以整条 `assistant.message` 到达。CLI 因此**同时**保留 inline 处理
> `text.delta`，并在没有 delta 时回退打印 `assistant.message.content`，确保答案不丢。
> 修复循环不在本里程碑的文件范围内，故未改动。

## 6. 约束遵守

- **未加第三方运行时依赖**；`tsx` 是唯一新 devDep（已在 store 内）。在 worktree 跑了
  `pnpm install` 并**提交了 `pnpm-lock.yaml`**（新增 `packages/cli` importer）。
- **默认行为不回归**：fork/diff 均为追加；Diff tab 仅在存在 diff 时出现；写工具在
  无变化时不发事件；web build/typecheck 全绿。
- `.env` 仅本地复制（gitignored，**未提交**）。
- **未触碰任何 mechanism 模块**。
- 增量提交（fork → diff → cost → CLI → 尾行修正）：
