## 1. 审批实验（真实模型，`approval-experiment.ts`）

复现：

```bash
pnpm --filter @agent/server exec tsx scripts/approval-experiment.ts --salt=m12a
```

三部分：0 是零 API 的命令自测，1/2 是两次真实 turn（gate 用打包的 M6 有序策略，
`write_file ⇒ ask`；`approvals` 回调里 `sleep(250ms)` 再返回裁决）。

### Part 0 — 命令注册表自测（零 API，12/12 PASS）

```
PASS  /help parses
PASS  /memory query parses
PASS  /etc/hosts is NOT a command          ← 路径陷阱
PASS  plain text is not a command
PASS  /help lists all four builtins
PASS  /memory calls the host recall
PASS  /memory reply contains the hit
PASS  /memory with no query returns usage
PASS  /workers returns the snapshot
PASS  /compact returns the report
PASS  unknown /foo parses but is unregistered (falls through to the model)
PASS  inject result appends a tail message (no system rewrite)
```

### Part 1 — deny 阻断（真实 turn）

```
-- deny: event sequence for call_b95216b49ec44acf940d3552 --
  tool.call → permission.decision → approval.requested → approval.resolved
  pause: requested.at=1791096373414 resolved.at=1791096373677 Δ=263ms
PASS  deny sequence = tool.call,permission.decision,approval.requested,approval.resolved
PASS  approval callback was awaited (pause ≥ delay)
PASS  file was NOT created
PASS  no tool.result for the gated call
PASS  model received a Denied tool message
```

`Δ=263ms` ≥ 回调里的 `250ms` 睡眠：**循环确实停在 promise 上**，不是"发完事件继续
跑"。deny 时没有 `tool.result`——模型拿到的是 `Denied: writes mutate the workspace`
工具消息，文件不存在。

### Part 2 — allow 执行（真实 turn）

```
-- allow: event sequence for call_952c26683173427fbecde46b --
  tool.call → permission.decision → approval.requested → approval.resolved → tool.result
  pause: requested.at=1791096377989 resolved.at=1791096378253 Δ=264ms
PASS  allow sequence = tool.call,permission.decision,approval.requested,approval.resolved,tool.result
PASS  approval callback was awaited (pause ≥ delay)
PASS  file exists after allow
PASS  file bytes contain the sentinel
  allow file content: "M12-ALLOW-m12a"
  allow file bytes=14 sha256=f493a8614fb295058fe9c45af437742324a02cbd28a258c6a3269c7f1b4e168c
```

allow 时工具真的执行，文件字节 `M12-ALLOW-m12a`（14B，
`sha256 f493a861…`）。事件顺序正是 brief 要求的
`permission.decision → approval.requested → approval.resolved → tool.result`
（`tool.call` 在 `permission.decision` 之前，属于既有 L0 语义）。

## 2. 服务器端到端（真 SSE + 真 POST）

用 `POLICY_FILE=packages/core/src/mechanisms/hooks/fixtures/rules.json`
（`write_file ⇒ ask`）、`MEMORY_ENABLED=true`、`ORCHESTRATOR_ENABLED=true`、
`APPROVAL_TIMEOUT_MS=1500` 启动，再用一个临时 HTTP 脚本驱动。全部 PASS：

### 斜杠命令无模型 turn

```
PASS  /help answers without a model turn     frames=[mechanism,assistant.message,turn.end]
PASS  /help returns a synthetic reply        ("Available commands:\n  /compact …")
PASS  /memory answers without a model turn   frames=[mechanism,assistant.message,turn.end]
      reply: "<memories>(none)</memories>\nNo memory matched \"cache rule\"."
PASS  /workers answers without a model turn  frames=[mechanism,assistant.message,turn.end]
      reply: "No workers registered.\nusage: 0 tokens, $0.000000"
PASS  /compact (manual)                       reply: "Compacted 0 → 0 tokens (summarized 0, kept 0 recent)."
```

命令帧只有 `mechanism(command) + assistant.message + turn.end`，**没有**
`context.compiled`/`usage`，即没有模型请求。

### 未知斜杠输入进模型

```
PASS  /foo falls through to a model turn      frames=[turn.start,context.compiled]
```

`/definitely-not-a-command …` 不在注册表里 ⇒ 原样 `agent.run`，出现 `context.compiled`
（模型 turn 的判据）。

### 审批 allow / deny / timeout（真 SSE 帧 + 真 POST）

```
=== approval via server: allow ===
    POST /approvals -> 200 {"ok":true,"toolCallId":"call_6ae99…","decision":"allow"}
  frames: … tool.call, mechanism, permission.decision, approval.requested,
          approval.resolved, tool.result, … turn.end
PASS  allow: approval.resolved = allow
PASS  allow: tool.result present
PASS  allow: file written with sentinel   ("M12-ALLOW")

=== approval via server: deny ===
    POST /approvals -> 200 {"ok":true,…,"decision":"deny"}
  frames: … tool.call, … permission.decision, approval.requested, approval.resolved, context.compiled
PASS  deny: approval.resolved = deny
PASS  deny: file NOT written

=== approval via server: timeout ===        (APPROVAL_TIMEOUT_MS=1500，不发 POST)
  frames: … approval.requested, approval.resolved, context.compiled
PASS  timeout: approval.resolved = deny
PASS  timeout: file NOT written
    timeout resolved in ~1513ms
```

即：**真 `ask` 产生 `approval.requested` SSE 帧**；POST `allow` 执行、POST `deny`
阻断、超时 `deny`（fail closed）。路由边界：

```
PASS  unknown toolCallId -> 409
PASS  unknown session -> 404
PASS  bad decision -> 400
```

## 5. 结论

- `ask` 现在是**被 await 的真实决策**：实验里 `Δ≈264ms` 证明循环停在异步回调上。
- 事件顺序固定：`permission.decision → approval.requested → approval.resolved → tool.result`（allow）。
- 超时 `deny` 兜底，turn 不会挂死；路由 `404/409/400` 边界清楚。
- 斜杠命令是**输入预处理**：命中命令零模型 turn；`/etc/hosts`、`/foo` 原样进模型。
- 两条路径都只**追加**消息，不重写缓存前缀；未配置路径与 master 逐字节一致。
